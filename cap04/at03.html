2. 🏆 Ranking de Tecnologias (relevância para o curso)

Ordem decrescente: da 5ª posição (menos prioritária) para a 1ª (mais importante).

  1. 5º - jQuery

    Biblioteca que simplificava manipulação do DOM e AJAX. Hoje menos usada, mas ainda presente em projetos legados.

  2. 4º - Bootstrap

    Framework CSS que acelera prototipagem. Básico para entender grids e componentes prontos.

  3. 3º - TypeScript

    Superset tipado do JavaScript. Essencial para projetos grandes e manutenibilidade.

  4. 2º - Node.js

    JavaScript no backend. Fundamental para desenvolvimento full stack e ferramentas modernas.

  5. 1º - JavaScript (vanilla + ES6+)

    Linguagem central da web. Indispensável para frontend, backend (Node) e automação.

3. 📖 Glossário Técnico

HTML
HyperText Markup Language – linguagem de marcação para estrutura de páginas web.
Define elementos como títulos, parágrafos, links e seções semânticas.
CSS
Cascading Style Sheets – linguagem para estilização visual (cores, fontes, layout).
Permite responsividade e animações, separando apresentação do conteúdo.
DOM
Document Object Model
Representação em árvore do documento HTML/XML, manipulável via JavaScript para alterar dinamicamente elementos e estilos.
JavaScript
Linguagem de programação interpretada que adiciona interatividade, manipula eventos e comunica com servidores (AJAX/Fetch).
URL
URI
Uniform Resource Locator/Identifier – endereço único de um recurso na web (ex: https://exemplo.com/pagina).
API
Application Programming Interface – conjunto de regras que permite integração entre softwares (ex: REST API).
HTTP
HyperText Transfer Protocol – protocolo de comunicação cliente-servidor para transferência de dados na web.

Total de termos: HTML, CSS, DOM, Document Object Model, JavaScript, URL, URI, API, HTTP (9 termos).
