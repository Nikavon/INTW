## Descricao
O projeto utiliza CSS Grid para a estrutura principal da pagina, criando um layout de duas colunas (conteudo principal + sidebar). Flexbox foi utilizado para organizar os elementos dentro das secoes de conteudo e para a disposicao dos itens na sidebar.

O design foi inspirado em elementos botanicos, utilizando uma paleta de cores verdes e tons terrosos, com detalhes dourados que remetem a um jardim sofisticado.

### Principais decisoes de layout:
- CSS Grid para o layout principal (2 colunas em desktop)
- Flexbox para sidebar e organizacao de conteudo
- Paleta de cores inspirada em jardins botanicos
- Tipografia com fontes serifadas elegantes
- Design responsivo com 3 breakpoints (1024px, 768px, 480px)
- Efeitos hover em todas as secoes interativas
- Animacoes sutis de entrada (fadeIn)
- Modo escuro automatico via prefers-color-scheme

## Recursos Utilizados
- CSS Grid Layout
- Flexbox
- Variaveis CSS (:root)
- Media Queries
- Animacoes CSS (@keyframes)
- Pseudo-elementos (::before, ::after)
- Sistema de cores com modo claro/escuro
- Transicoes e transformacoes CSS
